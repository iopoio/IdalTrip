## 1. 문제 정의 (Problem)

### 1.1 사용자 문제
- **결정 피로**: 평균적인 사용자가 한 번의 주말 여행을 정하기 위해 검색·비교에 적지 않은 시간을 씀
- **흩어진 정보**: 축제 정보(한국관광공사), 맛집(카카오·블로그), 관광지·즐길거리(개별 사이트), 숙소(예약앱) 각자 따로 검색해야 함 → *통합 큐레이션 빈 자리*
- **즉흥 결정의 마찰**: 금요일 저녁 "내일 어디?" 떠올라도 숙박 예약·경로 설계 부담으로 포기
- **지역 축제 발견 불가**: 비수도권에 매력적인 계절 축제가 풍부하지만 일반 사용자에게 노출 X → 대도시 쏠림 가속

### 1.2 시장 데이터 (컨슈머인사이트 2026.01)
- 국내 숙박여행 계획률 **65.9%** (코로나 절정기 수준)
- 국내여행 지출의향 **48p 급락** (2022년 정점 대비 2025년)
- "**예산 절약 → 부실한 경험 → 낮은 가심비 → 불만족** 악순환"
- "대도시 선호로 **전통 주말·계절 관광지 존립 위기**, **지방·중소도시 관광산업 기반 약화**"

### 1.3 풀어야 할 핵심
사용자가 *비용을 늘리지 않으면서 가심비를 회복할 수 있는* 디지털 채널이 필요. 한국관광공사가 보유한 풍부한 공공 데이터를 *사용자 친화적으로 재구성*하여 *지역 축제 발견과 즉시 결정*을 돕는다.

## 2. 비즈니스 목표 (Objectives)

### 2.1 미션
**"고민하지 마세요. 이번 달은 여기 가세요."** — 계절 축제와 그 주변 4요소를 한 번에 묶어 *다음 날 출발 가능한 주말 계획*을 클릭 한두 번에 완성.

### 2.2 단기 목표 (~6개월, 본 사업 V2 진입 시)
- 라이브 사용자 MAU 1,000+ 도달
- 월 평균 여행 계획 완성률 30%+ (방문 → 카카오내비 클릭 전환)
- 비수도권 축제 노출 비중 50%+ (6권역 균등)
- 다출처 검증 신호 평균 0.7+ (10점 만점)

### 2.3 장기 목표 (1년+)
- B2B API 라이선싱 (외부 여행사·플랫폼)
- 지자체 B2G 제휴 ("이달여행 공식 등재 축제" 라벨)
- 다국어 확장 (인바운드 시장)

## 3. 사용자 세그먼트 (Personas)

### 3.1 1차 타깃 — 즉흥 주말 여행자
- 30~40대 도시 거주 (서울·경기 중심)
- 자차 보유, 주말 1~2일 단위 여행
- 결정 피로 심함, 정보 검색에 시간 들이기 싫음
- 대표 시나리오: "금요일 저녁 퇴근 후, 내일 어디 가지?"

### 3.2 2차 타깃 — 계절 축제 애호가
- 가족 단위 또는 커플
- 봄꽃·단풍·눈꽃 등 시즌 축제 좋아함
- 매년 같은 축제 가는 사람 + 새 축제 발견 원하는 사람 둘 다 포함
- 대표 시나리오: "올해 봄꽃은 어디 가지? 새로운 축제 추천 받고 싶다"

### 3.3 3차 타깃 — 비수도권 거주자
- 지역에서 가까운 축제 발견 채널 부족
- 수도권 위주 정보 노출에서 소외
- 대표 시나리오: "내 위치(부산·대전·광주 등) 근처 축제 알려줘"

## 4. 가치 제안 (Value Proposition)

### 4.1 핵심 가치
**여행 4요소(좋은 장소 + 맛집 + 즐길거리 + 숙소) × 계절 축제 × 내 위치 × AI 동선** 을 한 번에 묶어 *결정 부담을 0에 가깝게* 낮춤.

### 4.2 차별화 4축

| 축 | 내용 |
|---|---|
| ① Zero-input | 사용자 별도 입력 없이 진입 즉시 큐레이션 노출 |
| ② 시간 × 공간 | 월별(시간) × 6권역(공간) 교차 큐레이션 |
| ③ 4요소 × 계절 축제 통합 | 축제 + 좋은 장소·맛집·즐길거리·숙소를 한 화면에 묶음 |
| ④ 다출처 검증 신호 집계 | 카카오 메타데이터 + 사용자 리뷰 + 미디어 노출 + 공인 가이드 종합 |

### 4.3 사회적 가치
- 지역 계절 축제의 *발견 채널* 제공 → 비수도권 관광 활성화
- 공공 관광데이터(TourAPI)의 사용자 체감 확대

## 5. 솔루션 (Features)

### 5.1 v1 유지 기능 (Phase 5 안정화 완료)
1. 진입 즉시 시즌 축제 피드 (전국·6권역)
2. 축제 상세 + 주변 탐색
3. AI 코스 자동 생성 (Gemini)
4. 경량 경로 엔진 (자체 하버사인)
5. 카카오맵 내비 직연결

### 5.2 v2 신규·확장 기능

#### F-A. 내 위치 기반 거리순 정렬 + 당일치기 가능 배지
- Geolocation API로 사용자 위치 자동 감지 (권한 한 번)
- 모든 축제 카드에 *거리(km)* 자동 계산·표시
- 왕복 이동 + 체류 시간이 하루 안에 가능한 축제에 *🎯 당일치기 가능* 배지 자동 부여
- 필터: [당일치기] [1박2일] [전체]
- 프로토타입: `/preview/distance-bundle`

#### F-B. 4요소 통합 큐레이션 화면
- 축제 클릭 → 자동 코스 + 동선 위 *좋은 장소·맛집·즐길거리* 카드 자동 노출
- 카테고리별 배지 (🌸 시즌 축제 / 🚗 드라이빙 맛집 / 🚶 즐길거리 / 📸 좋은 장소)
- 사용자가 마음에 드는 카드 코스에 추가 가능
- 프로토타입: `/preview/festival-bundle`

#### F-C. 코스 동선 기반 숙박 추천 + 1박2일 자동 확장
- 코스 결과 화면 하단에 *동선상 가까운 추천 숙소 3종* 노출 (거리·평점·검증 신호)
- 사용자 체크 → 1박2일 코스로 자동 확장 (다음 날 일정 추가)
- TourAPI 32번(숙박) 통합

#### F-D. 다출처 검증 신호 집계
- 카카오 지도 메타데이터 (평점·리뷰·인기 동선·드라이빙 맛집 카테고리)
- 사용자 리뷰 (네이버·블로그 언급 빈도)
- 미디어 노출 (인기 여행·먹방 콘텐츠 출연 데이터, 본 사업 단계 제휴 협의)
- 공인 가이드 (텍스트 매칭, 본 사업 단계 라이선스 협의)
- 카드별 *검증 신호 바 0~10*  표시

#### F-E. 자차 이동 코스 드라이빙 맛집 강화
- 자차 선택 시 카카오 *드라이빙 맛집* 카테고리 자동 매시업
- 휴게소·국도변·관광지 인접 식당 자동 추천
- "이동 자체가 가심비를 보강하는 경험" 컨셉

#### F-F. (장기) 임박 예약 가능 숙소 매칭
- 즉흥 결정 시나리오 (금요일 저녁 → 내일·모레)에서 *임박 예약 가능* 숙소만 필터링
- 예약 사이트 직연결 (제휴 협의 후)

#### F-G. TourAPI searchStay2 통합 (숙박정보 공식 데이터)
- 한국관광공사 공식 *숙박정보 API*로 F-C 1박2일 확장의 *데이터 출처* 강화
- 카카오 외부 변수 없이 *공식 데이터*로 정확도·신뢰도 확보
- 공모전 심사 *TourAPI 활용 다양성* 가산점 영역
- 객실·시설·운영 정보 자동 매핑

#### F-H. TourAPI detailImage2 활용 (축제·관광지 공식 이미지)
- 한국관광공사 공식 *이미지정보 API*로 카드 썸네일 자동 노출
- 외부 이미지 (Unsplash·Picsum) 의존 0
- *진짜 한국 축제·관광지 사진*으로 진정성·신뢰도 ↑
- 프로토타입에서 발생한 외부 이미지 fail 문제 근본 해결

#### F-I. 반려동물 동반여행 카테고리 (차별화)
- 한국관광공사 *반려동물 동반여행정보 API* 활용
- 4요소(좋은 장소·맛집·즐길거리·숙소) 카드에 **🐾 반려동물 동반 가능** 배지 표시
- 별도 필터 ["반려동물과 함께"] 추가
- 새로운 사용자 세그먼트 (반려인 가족) 흡수
- 공모전 *지역특화 서비스* 또는 *융복합 서비스* 부문 가산점 영역

## 6. 사용자 흐름 (User Flow)

### 6.1 골든 시나리오 — 금요일 저녁 즉흥 결정

```
[금요일 저녁 19:00]
사용자: "내일 어디 가지?"
  ↓
[idaltrip.vercel.app 진입]
- 위치 권한 한 번 ✓
- 자동 큐레이션: 내 위치(서울 강남) 기준 가까운 순 5월 축제 5개
  ↓
['🎯 당일치기 가능' 필터 클릭]
- 5개 중 3개가 당일치기 가능 → 거리순 표시
  ↓
[가평 자라섬 봄꽃축제 카드 클릭]
- 자동 코스 (08:30 출발 → 10:30 축제 → 12:30 드라이빙 맛집 → 14:00 둘레길 → 16:00 전망대 → 17:30 복귀)
- 4요소 배지 (시즌 축제·드라이빙 맛집·즐길거리·좋은 장소)
- 검증 신호 평균 8/10
  ↓
[하단 "1박2일로 확장하시겠어요?" — 체크 X (당일치기 진행)]
  ↓
[카카오내비 시작 버튼 클릭]
- 카카오맵 자동 실행 → 토요일 출발
```

### 6.2 대안 시나리오 — 1박2일 확장

위 흐름에서 *1박2일* 체크 → 추천 숙소 3종 중 선택 → 다음 날 일정 자동 추가 → 카카오내비 시작.

## 7. 측정 지표 (Metrics)

### 7.1 North Star
**월간 여행 계획 완성률** = (카카오내비 클릭한 사용자 수) / (사이트 방문 사용자 수)
- 목표: 30%+ (즉흥 결정자 1/3이 실제 출발까지 도달)

### 7.2 입력 지표
- **DAU/MAU**
- **위치 권한 허용률** (목표 60%+)
- **'당일치기 가능' 필터 사용률**
- **4요소 카드 추가 평균 개수** (코스당)
- **1박2일 확장률** (당일치기 → 1박2일)

### 7.3 건강 지표
- **6권역 노출 균등도** (서울·경기 50% 이내)
- **검증 신호 평균** (카드별 0~10)
- **AI 코스 생성 성공률** (현재 96% 검증 완료)
- **카카오 비즈 심사 통과 여부**

### 7.4 알림 임계점
- 위치 권한 허용률 40% 미만 → UX 보강 필요
- 6권역 균등도 70% 이상 서울·경기 → 비수도권 데이터 보강
- 검증 신호 평균 0.5 미만 → 데이터 출처 보강
